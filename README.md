# 🇪🇸 Español

## 📖 Sobre el Proyecto

**Arduino Bootcamp** es una plataforma web educativa diseñada para
aprender Arduino de forma progresiva, práctica e interactiva.

El bootcamp combina teoría, programación, electrónica y proyectos
prácticos para que cualquier persona pueda comenzar desde cero y
desarrollar sus propios sistemas con Arduino.

La plataforma está disponible en español e inglés, permitiendo que
estudiantes de diferentes países puedan acceder al contenido.

### 🎯 Objetivos

- Aprender los fundamentos de la electrónica.
- Comprender el funcionamiento de Arduino.
- Programar utilizando Arduino IDE y C/C++.
- Trabajar con sensores, actuadores y componentes electrónicos.
- Crear proyectos prácticos y sistemas automatizados.
- Desarrollar habilidades para resolver problemas.
- Aprender mediante una plataforma web organizada y accesible.

## 🔌 Primer Programa Arduino

Ejemplo de un LED parpadeando:

```cpp
void setup() {
  pinMode(LED_BUILTIN, OUTPUT);
}

void loop() {
  digitalWrite(LED_BUILTIN, HIGH);
  delay(1000);

  digitalWrite(LED_BUILTIN, LOW);
  delay(1000);
}
```

### ¿Qué hace este programa?

El programa enciende el LED integrado de la placa durante un segundo
y lo apaga durante otro segundo, repitiendo el proceso continuamente.

## 🔌 First Arduino Program

Example of a blinking LED:

```cpp
void setup() {
  pinMode(LED_BUILTIN, OUTPUT);
}

void loop() {
  digitalWrite(LED_BUILTIN, HIGH);
  delay(1000);

  digitalWrite(LED_BUILTIN, LOW);
  delay(1000);
}
```

### What does this program do?

The program turns the board's built-in LED on for one second and off
for another second, repeating the process continuously.
